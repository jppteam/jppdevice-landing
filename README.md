# J++Device — landing page

A static Vue 3 landing page for the **J++Device**, a tiny open pocket handheld
running JPPDOS. White / black / yellow identity (accent `#FDF254`), Outfit
display type, and a live in-browser port of the real DemoScene on a simulated
128×64 OLED.

## Develop

```bash
npm install
npm run dev        # Vite dev server → http://localhost:5173
npm run build      # static build → dist/
npm run preview    # preview the production build
```

The build in `dist/` is fully static — deploy it to any static host
(the canonical domain is `jppdevice.by.m4l3vi.ch`).

## Where to edit content

Everything content-driven lives in `src/data/` — no markup edits needed:

- **`site.js`** — the single source of truth for **all external links, the
  J++Meetup details, and the run size**. These are **placeholders**; swap them
  here once confirmed. (GitHub URLs, meetup date, final run size.)
- `features.js`, `games.js`, `apps.js`, `specs.js` — section content.
- `roadmap.js` — firmwares + ecosystem items. Flip a `status: 'soon'` to
  `'shipped'` and the UI updates its badge automatically.
- `codeSamples.js` — the MicroPython / native-C clock app + SDK summary.

## The wordmark (traced from Outfit)

The `J++ Device` logotype is traced to SVG paths from the Outfit font
(`J++` = Black 900, `Device` = Regular 400), matching `banner.webp`. Regenerate
after a font change:

```bash
npm run trace-logo    # → src/assets/logo/logoPaths.js + public/favicon.svg
```

`Wordmark.vue` renders the traced paths with a CSS yellow bar (can bleed off the
viewport edge); `JppMark.vue` is the compact `J++` mark.

## The demoscene

`src/lib/demoscene.js` is a faithful JS port of the firmware's `demoscene.c`
(same 8 scenes, 64-step sine LUT, 4×4 Bayer dither, 3×5 font, sine scrolltext).
`OledScreen.vue` blits it to a `<canvas>` at native 128×64 (`image-rendering:
pixelated`), pausing offscreen and honoring `prefers-reduced-motion`.

## The device art

`DeviceFrame.vue` is an original SVG matching the enclosure outline
(`dev only assets/jppdevice outline.svg`) — transparent shell, top-center OLED,
lower-left d-pad, right action button. It has a `render` slot to drop in real
product renders later. The provided photo is **not** embedded.

## Social preview

`public/og.png` (1200×630) and `public/apple-touch-icon.png` are generated by
`scripts/gen-og.mjs` (all text traced to paths) plus a one-off browser
rasterization. Full OG / Twitter / JSON-LD meta lives in `index.html`.
